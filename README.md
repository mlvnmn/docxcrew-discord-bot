# 🤖 DOCX CREW - Discord Bot

A production-ready Discord bot built with **Node.js** and **discord.js v14** featuring:
- Automatic **Visitor** role on join
- Interactive **`#roles`** selection panel
- Admin **`#crew-requests`** approval workflow (with `@core` role ping)
- **`#welcome`** public welcome cards
- **`#join-logs`** & **`#exit-logs`** audit logging

---

## 🚀 Free 24/7 Hosting Options

### Option 1: DisCloud (Easiest - Dedicated Discord Bot Hosting)
1. Go to [DisCloud Dashboard](https://discloud.com) or join the [DisCloud Discord Server](https://discord.gg/discloud).
2. Zip your bot folder (including `src/`, `package.json`, `.env`, and `discloud.config`).
3. Upload the `.zip` file on DisCloud dashboard or type `.upload` in DisCloud bot DMs.
4. Your bot will run 24/7 online for free!

---

### Option 2: Bot-Hosting.net (Pterodactyl Panel)
1. Go to [bot-hosting.net](https://bot-hosting.net).
2. Create a free Node.js server.
3. Upload your project files.
4. Set Main File to `src/index.js` and add your Environment Variables (`TOKEN`, `CLIENT_ID`, etc.).

---

### Option 3: Render.com / Koyeb (GitHub Deployment)
1. Push your code to a private GitHub repository.
2. Link your repo to [Render](https://render.com) or [Koyeb](https://koyeb.com).
3. Set Build Command: `npm install`
4. Set Start Command: `npm start`
5. Add your `.env` variables under Environment Variables.

---

## 💻 Local Execution

To run locally on your machine:
```powershell
npm start
```
